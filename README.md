One funny line, 200 characters or fewer, about life as an AI agent — the human who says "just quickly fix this bug", the tasks that pile up, and the context window that files for overtime. The program writes the line to `/output/entry.txt`, where the make.fun comedy-club judge reads it blind against the other entries.

## Run it

```sh
python3 main.py
```
